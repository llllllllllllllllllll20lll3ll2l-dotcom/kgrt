# 🔌 ADB не подключается — полное руководство

Если на телефоне **не появляется запрос «Разрешить отладку по USB»** или бот пишет «устройства не найдены» — пройдите шаги по порядку.

## Сначала определите свой случай

Откройте командную строку (Win+R → `cmd`) и выполните:

```bat
adb devices
```

| Что видите | Что это значит | Куда идти |
|---|---|---|
| Пустой список (только `List of devices attached`) | Телефон не виден вообще | Шаг 1–4 |
| `unauthorized` | Телефон видит ПК, но вы не разрешили | Шаг 5 |
| `offline` | Сбой авторизации | Шаг 5–6 |
| `device` | Всё работает! | Можно запускать бота |
| `'adb' не является внутренней командой` | ADB не в PATH | Шаг 7 |

---

## Шаг 1. Включите режим разработчика

1. Настройки → О телефоне → **Номер сборки** → тапните **7 раз**, пока не напишет «Вы стали разработчиком»
2. Появится пункт «Для разработчиков» (в Системе или в поиске настроек наберите «разработчик»)

## Шаг 2. Включите отладку по USB

Настройки → Для разработчиков → **Отладка по USB** → ВКЛ.

### Особые случаи (часто встречаются в РФ):

**Xiaomi / Redmi / POCO (MIUI / HyperOS):**
- Включите **Отладка по USB**
- Включите **Отладка по USB (настройки безопасности)** — без этого ADB не заработает
- Включите **Установку через USB** (потребуется SIM + интернет, вставьте SIM)
- После включения может попросить перезагрузку — перезагрузите

**Samsung (One UI):**
- Включите **Отладка по USB**
- Отключите **Отключение разрешений при перезагрузке** (если есть)
- Если ADB не видит — отключите и снова включите отладку

**Realme / Oppo / Vivo:**
- Включите **Отладка по USB**
- Включите **Отладка по USB (разрешения)** / **USB-отладка (настройки безопасности)**
- Включите **Разрешить симуляцию местоположения** (иногда помогает)

**Huawei / Honor:**
- Включите **Отладка по USB**
- Включите **Разрешить HDB** (Huawei Development Bridge)
- Включите **Разрешить ввод через виртуальные устройства**

## Шаг 3. Правильный кабель и режим USB

1. **Кабель должен передавать данные**, а не только заряжать. Дешёвые кабели «только зарядка» не работают. Попробуйте другой кабель.
2. Подключите в **USB-порт на материнской плате** (сзади ПК), а не в хаб/удлинитель.
3. На телефоне при подключении выберите режим:
   - **Передача файлов (MTP)** — лучший вариант
   - Или **PTP**
   - НЕ «Только зарядка»

## Шаг 4. Отзовите разрешения и подключите заново

1. На телефоне: Настройки → Для разработчиков → **Отозвать разрешения на отладку по USB** (или «Отменить авторизацию»)
2. Отключите USB
3. Подключите снова
4. **Должен появиться запрос:** «Разрешить отладку по USB? Компьютер: DESKTOP-XXXX. Разрешить всегда для этого компьютера» → поставьте галочку → **Разрешить**

> Если запрос не появляется — попробуйте отключить и включить «Отладку по USB» при уже подключённом кабеле.

## Шаг 5. Если `unauthorized` / `offline`

```bat
adb kill-server
adb start-server
adb devices
```
Отключите/подключите телефон, подтвердите запрос на телефоне.

## Шаг 6. Драйверы на Windows

Если телефон не виден в Диспетчере устройств (или виден с жёлтым восклицательным знаком):

1. Установите **Google USB Driver**: https://developer.android.com/studio/run/win-usb
2. Или драйвер производителя:
   - Samsung: Samsung USB Driver
   - Xiaomi: Mi PC Suite / Xiaomi USB Driver
   - Huawei: HiSuite
3. Диспетчер устройств → ваш телефон → Обновить драйвер → Указать вручную → `C:\platform-tools\usb_driver` (или папку драйвера)

## Шаг 7. ADB не находится (`'adb' не является командой`)

1. Распакуйте Platform Tools в `C:\platform-tools`
2. Win+R → `sysdm.cpl` → Дополнительно → Переменные среды → Path → Изменить → Добавить `C:\platform-tools` → OK
3. Закройте и откройте командную строку заново
4. Проверьте: `adb version`

Или просто положите `adb.exe` рядом с `run_bot.py` — бот найдёт его сам.

## Шаг 8. Альтернатива без USB — Wi-Fi ADB

Если USB вообще не работает, можно подключиться по Wi-Fi (телефон и ПК в одной сети):

1. На телефоне: Настройки → Для разработчиков → **Отладка по Wi-Fi**
2. В командной строке:
```bat
adb pair 192.168.1.5:12345
```
(код и порт покажет телефон)
3. Затем:
```bat
adb connect 192.168.1.5:5555
adb devices
```

## Шаг 9. Проверка перед запуском бота

```bat
adb devices
```
Должно быть:
```
List of devices attached
XXXXXX	device
```

Если видите `device` — запускайте `python run_bot.py` → «Подключить ADB».
