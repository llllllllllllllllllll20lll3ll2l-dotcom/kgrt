# 🎯 Тактики боя — 5 тактик с переключателем

В боте тактику можно менять **прямо во время боя** (вкладка «Бот», радиокнопки справа).

## 1. Агрессивная
- **Суть:** давит сразу, ставит танки за мостом, не ждёт эликсир.
- **Когда использовать:** против медленных колод, когда у вас преимущество по эликсиру.
- **Как играет:** Гигантский миньон → Ведьма → Дровосек за мостом. Постоянный пуш по одной линии.
- **Плюсы:** быстрый урон по башням. **Минусы:** легко контрится.

## 2. Оборонительная
- **Суть:** ждёт атаки врага, отбивается и контратакует.
- **Когда использовать:** против агрессивных колод (Хог, Голем, ПЕККА).
- **Как играет:** Надгробье героя + Скелеты/Летучие мыши против танка. После обороны — контратака Гигантским миньоном + Ведьмой.
- **Плюсы:** экономит эликсир. **Минусы:** медленная.

## 3. Сбалансированная (по умолчанию)
- **Суть:** следит за эликсиром врага, играет по ситуации.
- **Когда использовать:** универсально, для большинства боёв.
- **Как играет:** защита при угрозе, атака при 8+ эликсире, поддержка при 5+.
- **Плюсы:** стабильно. **Минусы:** нет яркой фишки.

## 4. Цикл
- **Суть:** быстрый цикл дешёвых карт, чип-урон Принцессой и Бревном.
- **Когда использовать:** против медленных колод, для фарма корон.
- **Как играет:** Принцесса по башне + Скелеты/Летучие мыши/Бревно/Дровосек по кругу. Быстрый добор эволюции.
- **Плюсы:** быстрый цикл, много эволюций. **Минусы:** мало урона по башням.

## 5. Контр-пуш
- **Суть:** отбивает атаку и сразу идёт в контратаку выжившими войсками.
- **Когда использовать:** против колод с одним сильным пушем.
- **Как играет:** Надгробье + Летучие мыши отбивают танк, выжившие идут в контратаку с Ведьмой.
- **Плюсы:** максимум урона из одной атаки. **Минусы:** требует точной обороны.

## Как выбрать тактику
| Противник | Рекомендуемая тактика |
|---|---|
| Хог-цикл | Оборонительная / Контр-пуш |
| Голем / ПЕККА | Оборонительная |
| Гигант + поддержка | Контр-пуш |
| Медленная колода | Агрессивная / Цикл |
| X-лук / Мортира | Агрессивная |
| Неизвестная | Сбалансированная |

## Контр-таблица вашей колоды
- **Гигант/Голем/ПЕККА** → Надгробье героя + Гигантский миньон / Летучие мыши
- **Всадник/Кабан** → Надгробье героя + Скелеты
- **Шар/Дракончик** → Принцесса + Летучие мыши / Гигантский миньон
- **Мушкетёр/Волшебник/Ведьма** → Бревно + Дровосек / Летучие мыши
- **Скелетная армия/Орда** → Бревно + Принцесса / Дровосек
- **Спарки/Мегарыцарь** → Надгробье + Скелеты / Летучие мыши
- **X-лук/Мортира** → Дровосек + Гигантский миньон / Летучие мыши
