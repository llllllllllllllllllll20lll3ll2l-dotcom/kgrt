# ⚔️ Clash Royale Bot — KGRT

Полноценный бот с интерфейсом для Windows + ADB/scrcpy. Видит экран телефона, анализирует бой и играет сам.

> ⚠️ **Предупреждение:** автоматизация может нарушать правила Supercell. Используйте на свой риск — возможен бан аккаунта. Рекомендуется тестировать на твике.

## Что умеет бот

1. **Видит игру с телефона** — через ADB `screencap` (USB). Анализирует эликсир, таймер, руку карт.
2. **Играет сам** — кликает по экрану через ADB `input tap`.
3. **5 тактик боя** с переключателем прямо во время боя: Агрессивная, Оборонительная, Сбалансированная, Цикл, Контр-пуш.
4. **Полное обучение** — симуляция тысяч боёв + hill climbing по весам (вкладка «Обучение»).
5. **Все карты** — база из 156 карт с описанием, как играют, контриками (вкладка «Все карты»).

## Быстрый старт (Windows)

```bat
# 1. Установите Python 3.10+ с https://python.org (галочка Add to PATH)
# 2. Установите Android Platform Tools: https://developer.android.com/tools/releases/platform-tools
#    Распакуйте и добавьте папку в PATH (или положите adb.exe рядом с run_bot.py)
# 3. Включите USB-отладку на телефоне
# 4. Установите зависимости:
pip install -r requirements.txt
# 5. Запустите:
python run_bot.py
```

### Подключение телефона
1. Настройки → О телефоне → 7 раз тап по номеру сборки → Для разработчиков → Отладка по USB.
2. Подключите USB, разрешите отладку.
3. Во вкладке «Бот» нажмите «Подключить ADB» → «Запустить бота».

### Калибровка (если клики не попадают)
```bat
python tools/calibrate.py
```
Скрипт покажет, какие карты бот видит в руке (с уверенностью), и сохранит
`calibration_marked.png` — зелёные рамки = карта распознана, красные = нет.

Проверить распознавание без телефона: `python tools/selftest.py`

Замерить скорость на своём телефоне: `python tools/benchmark.py`

## Обучение

Вкладка «Обучение» → «Запустить обучение» (или «Обучить все тактики»).
Бот играет симулированные бои против 10 вражеских колод и подбирает веса.
Результат сохраняется в `data/trained_weights.json` и применяется автоматически.
